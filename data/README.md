# Data

This directory should contain the input data files required by the analysis scripts. Data files are not included in the repository due to size constraints.

## Required files

| File | Size | Source | Used by |
|---|---|---|---|
| `dataset_limpio.parquet` | ~121 MB | Generated by script 1 from raw dataset | Scripts 2-8 |
| `Raw dataset (.xlsx)` | ~509 MB | Google News RSS scraping via R (`cod_tesis.R`) | Script 1 |
| `IPC_ECOICOP.xlsx` | ~1 MB | [INE](https://www.ine.es/) — Consumer Price Index (ECOICOP classification) | Scripts 4, 5, 6 |
| `ICC.xlsx` | ~100 KB | [CIS](https://www.cis.es/) — Consumer Confidence Index | Scripts 4, 5, 6 |
| `afiliacion_ss.xlsx` | ~100 KB | [MITES](https://www.mites.gob.es/) — Social Security affiliations | Scripts 4, 5, 6 |

## Intermediate outputs (generated by scripts)

| File | Generated by | Used by |
|---|---|---|
| `emotion_results_full.parquet` | Script 2 | Scripts 3, 7, 8 |
| `monthly_emotions.csv` | Script 3 | Scripts 4, 5, 6, 8 |
| `censo_report.json` | Script 1 | Reference only |

## How to obtain the data

1. **Raw headlines**: The original dataset was collected using Google News RSS feeds for Spanish media outlets between 2014 and 2024. The R script `cod_tesis.R` (not included) performed the scraping.
2. **Macroeconomic indicators**: Download directly from the official Spanish statistical agencies (INE, CIS, MITES) using their public data portals.
3. **Processed dataset**: Run the scripts in numerical order starting from script 1, which cleans and filters the raw dataset into `dataset_limpio.parquet`.
