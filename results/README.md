# Results

This directory contains the outputs generated by the analysis scripts. All result files are included in the repository for reproducibility and verification of Chapters 6 and 7.

## Directory Structure

```
results/
├── arimax/                        # ARIMAX model outputs (Script 4)
│   ├── adf_tests.csv              # Augmented Dickey-Fuller stationarity tests
│   ├── all_results.json           # Full ARIMAX results (coefficients, diagnostics)
│   ├── arimax_results_full.xlsx   # Summary table of all models
│   └── *.png                      # 23 diagnostic plots (residuals, fitted vs actual)
│
├── var_granger/                   # VAR and Granger causality (Script 5)
│   ├── adf_tests.csv              # ADF tests for VAR variables
│   ├── granger_tests.csv          # Granger causality test results
│   ├── fevd_ipc.csv               # Forecast error variance decomposition (CPI)
│   ├── var_granger_summary.json   # Summary statistics
│   ├── fevd.png                   # Variance decomposition plot
│   └── irf_orthogonal.png         # Orthogonal impulse-response functions
│
├── structural_breaks/             # Structural break detection (Script 6)
│   ├── bai_perron_breaks.json     # Bai-Perron detected breakpoints
│   ├── chow_tests.json            # Chow test statistics (pre/post COVID)
│   ├── arimax_pre_post_covid.json # ARIMAX regime comparison
│   ├── ks_tests.csv               # Kolmogorov-Smirnov distribution tests
│   ├── structural_breaks_summary.json
│   └── series_con_quiebres.png    # Time series with detected breaks
│
├── validation/                    # LLM cross-validation (Script 7)
│   ├── llama3_full_validation_results.csv  # Per-headline RoBERTa vs Gemma 3 (16,651 rows)
│   └── llama3_full_validation_summary.json # Confusion matrix, Cohen's Kappa, F1 scores
│
├── econometric_dataset_global.csv      # Monthly aggregated emotions + macro indicators (Script 3)
├── econometric_dataset_by_category.csv # Same, disaggregated by news category
├── volume_dataset.csv                  # Monthly headline volume by source
└── censo_report.json                   # Dataset census statistics (Script 1)
```

## Reproducing Results

Run scripts in numerical order (1-8) from the `scripts/` directory. See the main `README.md` for setup instructions.

## Checkpoints

Scripts 2 and 7 support checkpoint-based resumption for long-running tasks. Checkpoint files (`*_checkpoint.json`) are saved periodically and excluded from version control via `.gitignore`.
